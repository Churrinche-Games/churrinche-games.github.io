# churrinche-games.github.io

The Churrinche Games website: a landing page and each game's privacy policy (es + en), served by
GitHub Pages from `main`. Plain HTML and CSS, no build step.

- `index.html`, `style.css`, `logo.png` (from game-kit's `docs/brand/churrinche-500.png`)
- `bichoku/privacy/` (kept in step with bichoku's `docs/privacy-policy.md`), `bichoku/icon.png`

Questions or problems with a game: open an issue here.
